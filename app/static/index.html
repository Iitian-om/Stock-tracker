About this board

StockDesk checks the local price worker and displays its latest saved readings. Data refreshes every 10 seconds.

Quote units: symbols ending in .NS are INR (Indian rupees); common US tickers such as AAPL are USD (US dollars); crypto pairs such as BTC-USD are USD. Other symbols are marked as source units.

Data mode: the default mock source makes demo prices. Set PRICE_SOURCE=yahoo for Yahoo Finance quotes.

For API details, visit the service docs.
